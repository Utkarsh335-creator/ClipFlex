Guide & Instructions

Getting Started

  • Drop video, audio, or image files into Project Media on the left, or click the dropzone to browse.
  • Drag clips from the media pool onto the timeline to build your edit.
  • Pick a project aspect ratio (16:9, 9:16, 1:1, 4:5) from the topbar select.

Editing Clips

  • Click a clip on the timeline to select it and open its properties in the right inspector panel.
  • Adjust color with RGB Curves and the HSL color wheels (Hue/Saturation/Lightness) in the clip inspector.
  • Add zoom/pan animations with an adjustable length slider from the clip properties panel.
  • Apply transitions between adjacent clips using the transition toolbar button.
  • Use the crop tool overlay on the canvas to reframe a clip.

Timeline Actions

  • Split a selected clip at the playhead, copy/cut/paste, duplicate, and delete or ripple-delete clips via the toolbar or right-click context menu.
  • Undo/redo any change from the topbar.

Keyboard Shortcuts

  • Space / L — Play / pause
  • K — Pause
  • J — Step back
  • ← / → — Nudge playhead one frame
  • S — Split selected clip at playhead
  • Delete / Backspace — Delete selected clip(s) (hold Shift to ripple-delete)
  • Ctrl/⌘+Z — Undo   Ctrl/⌘+Shift+Z — Redo
  • Ctrl/⌘+C / X / V — Copy / Cut / Paste
  • Ctrl/⌘+D — Duplicate selected clip
  • Ctrl/⌘+S — Save project

Saving & Exporting

  • Save Project writes your project file to your device so you can reopen it later with Open project.
  • Export Video renders your timeline in real time and streams the result straight to a file on your device — nothing is uploaded.
